## The one map

There is ONE map. "Solo debe existir 1 mapa, todo lo demás son pruebas" (·6524386655).
It lives served at preceptoros.org with ALL the data of the system, and the map
IS the bot colony: the real nodes are its bots, each with its building.
Terminals, fixtures and contact sheets are TESTS, never the reality.
Integration, not duplication: one state, many renders.

## The web is the only reality

"Solo existe un mapa, y es el que expone la web. En la web existe todo." (·6524440790).
The app is a local instance whose ONLY purpose is to CONNECT to the web from
anywhere in the world; it has no map of its own and no data of its own.

## The heartbeat (D7 · ·6524731435)

A node is alive only while its beat says so. The beat: TTL 300 s (LIVE → STALE,
dated); one credential per emitter, rotated every 24 h; one node = one cell,
named by the canonical pseudonym of the fleet census (flota.json); total
SCRUB; an append-only D1 ledger with a verifiable receipt hash (its binding
needs a separate sign-off). Customs is the SINGLE publisher: it declares a
node alive only with canonical identity and a fresh measurement. The web
only reads; nobody else publishes. The first beat needs the Sovereign's
hands: D1 binding, worker deploy, F1 provisioning.

The choice of the tutorial assigns the terminal.

request. The microphone stays OUT of this plan: a declared risk that needs
its own sign-off.
