# odd/ — Organic Driven Development

Adopted by FIRMO 2026-10-28; see `CONTRIBUTING.md` for the house rules.
A feature document is born when substantial authorized work starts and
dies when the feature lands; everything else stays as it was.

- `odd/tasks/<feature-name>.md` — one feature, one document, one name:
  objective, problem, why, checklist with stable IDs (`T1`, `T2`…),
  verification evidence, `## Log` (choices, chain decisions), next step.
- Work-unit commits: reviewable slices of about 400 authored lines
  (advisory, never a cap or a forced split). A high-risk unit gets its
  own commit.
- Work never halts for a signature: search the corpus for the standing
  signature, record the modification, continue.
- Delivery gates are never skipped: checks that can go red, the receipt,
  and `FIRMO` on the exact head.
