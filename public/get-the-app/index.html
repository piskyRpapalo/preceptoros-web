Update your existing PreceptorOS app

The public WEB cannot inspect or silently update an APP on another device. The native Android v16 APK in door A has package org.preceptoros.app, versionCode 16 and the same signer as legacy Android 1.0.1; Android verifies update compatibility. Keep existing data and never uninstall just to force an update. Browser-origin APP updates follow a separate path below.

  1. Android native: download v16 above, open it in Android, confirm the installer and keep your existing app data. If Android rejects an update, do not clear data; report the message.
  2. Browser/PC APP: on the device with your installed APP, use its existing shortcut or browser profile. Keep the original site data and identity keys; no public rack port is required.
  3. Reconnect your existing trusted tunnel, if you use one, and open the PreceptorOS APP from the original address saved on your own device. This public website cannot discover your local APP address or access your private node. Do not guess another server.
  4. In the APP, choose Settings → This app · install and update → Check for update. Compare the offline version and the version served by the rack. If the APP says the update is ready, choose Reload to use the update.
  5. If the control is absent, the installed browser copy may be older than this feature. Reopen the same trusted APP origin in your browser and check again. If it still does not appear, record NO_DATA(old_app_update_unavailable) instead of clearing app storage or identity keys.

Linux source installations: run the existing, reviewed installer again to request a fast-forward of the checked-out source. This is a different update mechanism from a browser service worker. Do not reinstall an Android OpenWorld APK to update a Linux or rack-hosted APP.

Node creation: in Android native v16 open My node → Node identity, enter your own details and choose Request admission with explicit consent. Aduana must answer with a verified receipt, then the Sovereign signs approval and provisions the node separately. Before you start

  • You need python3 and git. If one is missing, the installer stops and prints the exact command for your system.
  • The installer never asks for an administrator password and installs nothing behind your back.
  • Ollama is optional. Without it the app remembers, indexes and cleans text, but does not chat.
  • 8 GB of memory is enough for a small model. No graphics card is needed.
  • The installer's messages are in Spanish for now.

Ubuntu / Linux · historical v1.3 source installer

Ubuntu uses a historical install.sh, not a modern signed .deb or a new native APP 1.1. Check its fingerprint before running; compatibility with your system is not implied by the Android v16 release.

  1. Download install.sh.
  2. Check its fingerprint. sha256sum install.sh must print
    2bd8666979a67ea1ec8b01a01aac240acfc2cef6165b93e558d0b836d3df6e74
  3. Run it: bash install.sh. It clones the app into ~/preceptoros.
  4. Start it: cd ~/preceptoros && bin/preceptoros-servicio arranca, then open the local address it prints in your browser.
