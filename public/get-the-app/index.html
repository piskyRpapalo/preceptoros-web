Get the app

The app is your own node, on your own machine: local memory and a local AI that stay with you. Release v1.3 (2026-08-31).

In one or two clicks

  1. Without JavaScript, follow the steps below.

Five minutes? Nobody has timed a clean install yet, so that figure is NO_DATA. The steps are short; how long they take on your machine is yours to measure.

Before you start

  • You need python3 and git. If one is missing, the installer stops and prints the exact command for your system.
  • The installer never asks for an administrator password and installs nothing behind your back.
  • Ollama is optional. Without it the app remembers, indexes and cleans text, but does not chat.
  • 8 GB of memory is enough for a small model. No graphics card is needed.
  • The installer's messages are in Spanish for now.

Linux and macOS

  1. Download install.sh.
  2. Check its fingerprint. sha256sum install.sh must print
    2bd8666979a67ea1ec8b01a01aac240acfc2cef6165b93e558d0b836d3df6e74
  3. Run it: bash install.sh. It clones the app into ~/preceptoros.
  4. Start it: cd ~/preceptoros && bin/preceptoros-servicio arranca, then open the local address it prints in your browser.

Windows

  1. Download install.ps1. It has never been run: if it fails, the exact message is useful.
  2. Check its fingerprint. Get-FileHash install.ps1 must print
    b10d7b8ade7ea0f301fd325336ae97dba6fd954786956703a3c1c6a80641f19b

Android

  1. Download PreceptorOS-android-1.0.1.apk (1.3 MB), straight from this site. The same file is mirrored in the app's release. It is this web, installed as an app: it opens the world with no address bar and keeps nothing extra on the phone. Tested on an Android phone on 2026-11-09.
  2. Check its fingerprint. Its SHA-256 must be
    8db3176a20ed973dab1f28642972bb97ab1ccd70ddbc7cf95f7a44affc7c4d8b
  3. Open the file and allow the install. The app's signing certificate is declared at /.well-known/assetlinks.json.

To run the full app (the local model and the node) on Android, the app's own guide, INSTALACION_ANDROID.md (in Spanish), covers Termux.

First steps for collaborators

Each link opens one place of the map; in the Android app the same four are a long press on its icon. A link only opens and fills: you press Send or Play yourself.

  • Help and the missions waiting: the embers beside buildings are missions; tap one to open its card.
  • Public chat: text only, no account, erased within 24 hours.
  • The guide on this device: it downloads once and answers offline.
  • Hexelion, the AI on the rack: start a visit first; it advises and never signs.
  • The Agora, the Coliseum, the Workshop: a building's card, straight away.

Basic scripts to try with the guide (each fills the question; you send it):

  • What is this map?
  • How do I move?
  • What are the embers beside buildings?
  • What is a live node?
  • Hello Hexelion, what can you do?
