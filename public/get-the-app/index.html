Update your existing PreceptorOS app

The public WEB cannot inspect or silently update an APP running on another device or origin. The Android APK above updates only OpenWorld, not the nine-panel PreceptorOS APP.

  1. On the device with your installed APP, use its existing shortcut or browser profile. Keep the original site data and identity keys; no public rack port is required.
  2. Reconnect your existing trusted tunnel, if you use one, and open the PreceptorOS APP from the original address saved on your own device. This public website cannot discover your local APP address or access your private node. Do not guess another server.
  3. In the APP, choose Settings → This app · install and update → Check for update. Compare the offline version and the version served by the rack. If the APP says the update is ready, choose Reload to use the update.
  4. If the control is absent, the installed browser copy may be older than this feature. Reopen the same trusted APP origin in your browser and check again. If it still does not appear, record NO_DATA(old_app_update_unavailable) instead of clearing app storage or identity keys.

Linux source installations: run the existing, reviewed installer again to request a fast-forward of the checked-out source. This is a different update mechanism from a browser service worker. Do not reinstall an Android OpenWorld APK to update a Linux or rack-hosted APP.

Node creation: after updating, look in the APP's World panel for Create a node (proposal). It creates a pending proposal, not a remote server. A verified remote node trial and signed public admission are separate steps: NO_DATA(remote_node_deployment_not_verified).

Before you start

  • You need python3 and git. If one is missing, the installer stops and prints the exact command for your system.
  • The installer never asks for an administrator password and installs nothing behind your back.
  • Ollama is optional. Without it the app remembers, indexes and cleans text, but does not chat.
  • 8 GB of memory is enough for a small model. No graphics card is needed.
  • The installer's messages are in Spanish for now.

Linux and macOS

  1. Download install.sh.
  2. Check its fingerprint. sha256sum install.sh must print
    2bd8666979a67ea1ec8b01a01aac240acfc2cef6165b93e558d0b836d3df6e74
  3. Run it: bash install.sh. It clones the app into ~/preceptoros.
  4. Start it: cd ~/preceptoros && bin/preceptoros-servicio arranca, then open the local address it prints in your browser.

Windows

  1. Download install.ps1. It has never been run: if it fails, the exact message is useful.
  2. Check its fingerprint. Get-FileHash install.ps1 must print
    b10d7b8ade7ea0f301fd325336ae97dba6fd954786956703a3c1c6a80641f19b

Android

  1. Download PreceptorOS-android-1.0.1.apk (1.3 MB), straight from this site. The same file is mirrored in the app's release. It is this web, installed as an app: it opens the world with no address bar and keeps nothing extra on the phone. Tested on an Android phone on 2026-11-09.
  2. Check its fingerprint. Its SHA-256 must be
    8db3176a20ed973dab1f28642972bb97ab1ccd70ddbc7cf95f7a44affc7c4d8b
  3. Open the file and allow the install. The app's signing certificate is declared at /.well-known/assetlinks.json.

To run the full app (the local model and the node) on Android, the app's own guide, INSTALACION_ANDROID.md (in Spanish), covers Termux.
