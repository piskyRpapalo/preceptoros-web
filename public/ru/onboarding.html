1Что такое PreceptorOS?

Твой ИИ на твоей машине, без обязательного облака. Постоянная память, которая принадлежит тебе, и Privacy Gateway, который вычищает контекст, прежде чем тот уйдёт к любому внешнему ИИ. Без учётных записей, без телеметрии.

2Твоя приватность, твой контроль

Именно фильтр вычёркивает личное. Вставь свой контекст и посмотри, что выйдет, прежде чем отдавать его кому-либо: это происходит в твоём браузере, без установки, и он честно говорит, куда НЕ достаёт.

3Скачай приложение

Сайт — витрина. Приложение — мастерская: там выбранный тобой спутник по-настоящему работает с твоими файлами, не выпуская их с твоей машины.

Android · через Termux Linux o macOS · install.sh Windows · install.ps1

NO_DATA — сегодня Android идёт через Termux, по руководству этого сайта; APK объявлен как будущее и пока не существует. Настольные установщики указывают на свой окончательный адрес в GitHub Releases и будут отдавать 404, пока не выйдет первая версия. Windows и macOS на этой стойке НЕ проверены: здесь нет ни одной машины с этими системами.

4Твой код привязки

Твоя личность создаётся в браузере, и закрытый ключ его не покидает. Этот код привязки выводится из твоего открытого ключа: он всегда один и тот же для тебя и не содержит внутри никакой тайны.

Этот код ТЕБЯ ОПОЗНАЁТ, но не удостоверяет: любой, кто знает твой открытый ключ, может его вычислить. Настоящая привязка потребует ещё и подписи, а она придёт вместе с сервером.
