Descarga direta

Android · por Termux Linux o macOS · install.sh Windows · install.ps1

Os três vão para o GitHub Releases. Até sair a primeira versão dão 404 — é o NO_DATA de cima, dito onde se carrega.

Num computador · Linux ou macOS

  1. Confirma que tens Python.

    python3 -V — hace falta 3.10 o más nuevo. Si falta, el instalador di-lo e para: não o instala com sudo, porque pedir uma palavra-passe a meio de um guião é como se enfiam as surpresas.

  2. Clona o repositório.

    git clone --depth 1 https://github.com/piskyRpapalo/PreceptorOS ~/preceptoros

  3. Cria a porta.

    cd ~/preceptoros && bash bin/instalar-pc — põe o ícone no teu menu de aplicações e nada mais. Não arranca nada ao terminar: cria a porta; entrar decides tu. Para o tirar, bash bin/instalar-pc --desinstalar, que apaga o ícone e não toca na tua memória.

  4. Cria a tua memória.

    python3 preceptoros.py — faz-te as perguntas do primeiro arranque. Começa vazia, e di-lo.

  5. Abre a cara web.

    bin/preceptoros-servicio arranca y ve a http://127.0.0.1:8740. É a tua máquina a falar consigo mesma: esse 127.0.0.1 no sale de ahí.

No Windows · por WSL

No hay pasos propios: dentro de WSL tens um Linux, por isso servem os de cima tal como estão. Abre wsl e segue a secção de Linux. Dizemo-lo aqui para que não o procures.

Num telemóvel Android · por Termux

  1. Instala Termux a partir do F-Droid.

    Não do Google Play: essa versão está abandonada e falha. É o erro que mais gente perde no primeiro minuto.

  2. Traz o git e o repositório.

    pkg install -y git
    git clone --depth 1 https://github.com/piskyRpapalo/PreceptorOS ~/preceptoros

  3. Prepara o telemóvel.

    cd ~/preceptoros && bash bin/instalar-android

  4. Memória, atalho e cara web.

    python3 preceptoros.py
    bin/crear-acceso-directo-android (opcional, recomendado)
    bin/preceptoros-servicio arranca, y abre http://127.0.0.1:8740.

    Para que o atalho saia como ícone é preciso Termux:Widget (también de F-Droid). Si no está, el guion lo dice y explica qué hacer — no crea un icono que no va a aparecer.

NO_DATA · o APK que se instala e se abre sem terminal ainda não existe. Causa: ninguém o construiu. Dizemo-lo antes de que o procures.

O que faz desde o minuto um, e o que ainda não

Faz: cria a tua memória, faz-te as perguntas do primeiro arranque, guarda o que lhe contas, e mostra-te a fronteira — o filtro que risca chaves, caminhos e moradas antes de que um texto saia da tua máquina.

Ainda não faz: conversar. Para eso faltan dos piezas grandes que no caben dentro y não se descarregam sem a tua permissão:

O motor · ~10 MB · Es código ejecutable de otros. Este proyecto firma datos, no programas.

O cérebro · 2,3 GB · Oferece-se com a sua licença e a sua impressão à frente, e aceita-lo tu.

Sem elas, o PreceptorOS pergunta e recorda mas não conversa. É a descrição honesta, e não promete mais do que traz dentro.

Onde fica o que é teu

En ~/.preceptoros/memory.db. Um só ficheiro. Puedes copiarlo, llevártelo en un USB o borrarlo. Nada sale de tu máquina si tú no lo exportas.

Se já o tinhas instalado com o nome antigo, a tua memória fica onde está e continua a funcionar: o produto adota a casa velha em vez de mover os teus dados por sua conta.

Erros comuns

«O PreceptorOS já estava aberto». Lo está. Se abrió el navegador y no se arrancó un segundo, porque dos a la vez sobre la misma memoria haría que vieras una cosa y el fichero dijera otra.

«O servidor não chegou a responder». Algo ocupa a porta 8740. bin/preceptoros-servicio para cierra lo que haya.

«falta python3». El instalador para ahí a propósito. Instálalo tú y vuelve.

O Termux fecha-se ou falha de forma estranha. Quase sempre é a versão do Google Play. Desinstala-a e põe a do F-Droid.
